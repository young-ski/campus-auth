# 发给同学：文案与反馈协议

面向「只发给关系好的同学」这一档：口头/私聊为主，不投校园墙，不做 star 运营。
所有文案都按同一个顺序：**干什么用 → 但是第三方 → 先连热点 → 解压双击 → 卡住发什么给我**。

## 发之前（缺一条就别发）

- [ ] 1.7.x 已打 tag 并发布，Release 里有 `campus-auth-<版本>-win.zip` 和 sha256
- [ ] 自己解压跑过一遍完整流程（不是只看构建成功）
- [ ] 手上存着 zip 的 sha256，文案里一起给
- [ ] 默认适配层、门户地址、账号格式都没变（变过就先自己重跑 `status`）
- [ ] 一次最多发 3 个人，走完再扩

## 首条私聊 · 短版

> 我写了个校园网自动登录的东西，装一次以后不用每次点门户，掉线它自己重连。
> 第三方的、学校没官宣，介意就算了。
> 要先连手机热点再下载（没认证的时候下不了）。
> 想试的话回我，我把文件发你。

## 首条私聊 · 标准版

> 给你发个我写的小工具：**校园网自动登录**。装一次，以后不用每次开浏览器点门户，断了会自己重连。宿舍也能用（会问你是哪个网）。
>
> 三点先说清楚：
> 1. 第三方写的，学校没出过规定，用不用你自己判断；
> 2. **装之前先连手机热点**，认证前上不了网，下载会失败；
> 3. 只登录/保活，不改计费、不绕套餐。
>
> 不装也不影响啥。想试就回我，发你压缩包（带校验码）。装的时候有任何不对，直接把屏幕最后几行复制给我。

## 群里/多人版（只在真发到 3 人以上时用）

> 写了个校园网自动登录，装一次就不用每次点门户了，断线自己重连。
> 第三方的，学校没规定，自担风险；先连热点再下。
> 只有 Windows、要 Python 3.11+，`install.cmd` 会带你装。
> 装不上的把「系统版本 / 卡在第几步 / 最后几行输出」发我。

## 追问与常见回复

| 对方说 | 回什么 |
|---|---|
| 会不会封号 | 不清楚，学校没规定。它就是你平时点门户的那套请求，只是自动发 |
| 会不会偷密码 | 不连任何中转服务器，全直连学校门户。密码存系统钥匙串，不进配置文件（钥匙串用不了才会写进去，包里的说明写了） |
| 要装 Python？ | `install.cmd` 会检查，没有就开下载页，勾上「Add python.exe to PATH」再双击一次 |
| 我装完没用啊 | 先跑 `campus-auth status` 看是不是真在线；再看是不是连的热点而不是校园网 |
| 能开机自动跑吗 | 安装最后一步选 y。不想要就 `campus-auth uninstall` |
| 学校会不会管 | 不知道。真被找上门也就自己卸掉，没改计费 |

## 对方不想用 / 装不上时

- 装不上：别硬推，收走四要素就够了，回来我改。
- 不想用：「行，卸载跑 `campus-auth uninstall` 再删 `%APPDATA%\campus-auth` 就行」。
- 千万别替他远程装——装一台你会失去那台机器的真实卡点。

## 反馈模板（发给同学，让他直接复制填空）

> 卡住的话照这个填，把最后几行原样复制（**不用打码密码**）：
>
> ```
> 系统：Win10 / Win11 / 别的
> 装之前连的是：热点 / 校园网 / 都有
> 卡在第几步行：1 解压　2 双击 install.cmd　3 填学号　4 输密码　5 自动验证　6 问自启　7 装完了
> 屏幕最后几行（或截图）：
>
> ```

用聊天软件发时，可以直接把上面那段单独发一条，别和文件混在一条里。

## 你转给我时（别替我总结）

原样贴，四要素一条不少。**「他说卡在第三步」和「他看到 `account 还是空的`」是两回事**，后者才能定位。

| 昵称 | 时间 | 系统 | 装前连的什么 | 卡点原文 | 有没有 Python | Defender 提示 | 是否解决 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

另外单独记，不放进表里：**装完还会不会用第二天**（隔一天问一句就行）。

## 前 3 个人之后

满足下面全部才扩到 5–8 人：

- 3 人里至少 2 人自己装完了，没让我代劳
- 没出现「必须装 Python 才能用」之外的新阻塞
- 没有一个人第二天掉线且自启没拉起来

达不到就先修，别扩。扩出去再翻车，口碑修起来比代码慢。

## 不要说的话

- 「官方的」「学校推荐」——都不是
- 「绝对安全」「不会封号」——没人验证过
- 「一行命令就行」——对不会命令行的人是假的
- 「很简单啊」——他一卡住就不好意思再问
