campus-auth 安装说明
====================================================================

河南城建学院校园网的命令行客户端。装好之后一行命令登录、断线自动重连。
只支持本校的 Dr.COM / eportal 门户。

本工具是第三方项目，学校没出过明文规定，用不用你自己判断，出了事自己担。
细节见同一个文件夹里的 免责.txt。


一、先做这一步（很重要）
--------------------------------------------------------------------
还没登录校园网时，pip、网页、下载都上不了。所以：

  **先连上手机热点或流量**，或者先在能上网的时候把这一整套准备好，
  再连校园网（UCLINK / UCSIG）跑安装。

已经连了校园网但还没登录，也可以直接装 —— 只是装完得在校园网里用。


二、装
--------------------------------------------------------------------
1. 把整个压缩包解压到一个文件夹（别在压缩包里双击）。
2. 双击 install.cmd。
3. 按提示做：
   - 它会自己检查有没有 Python；
   - 打开配置文件让你填学号（只填数字，别带 @cmcc）；
   - 问你要密码（输入时不显示）；
   - 当场登一次，看通不通；
   - 最后问要不要开机自启，建议选 y。
4. 窗口说 Done 就完事。

配置和密码存放位置：
  配置  %APPDATA%\campus-auth\config.toml
  日志  %LOCALAPPDATA%\campus-auth\watch.log
装完把解压出来的文件夹删掉也不影响使用。


三、没有 Python 怎么办
--------------------------------------------------------------------
install.cmd 会告诉你，并自动打开下载页。装的时候**一定要勾上
"Add python.exe to PATH"**，否则装完还是找不到。

需要 3.11 或更新的版本。


四、日常怎么用
--------------------------------------------------------------------
开个命令行（Win+R 输入 cmd）：

  campus-auth status      看现在在不在线（推荐先跑这个）
  campus-auth login       手动登录一次
  campus-auth logout      注销
  campus-auth doctor      出问题时跑它，把输出发出来

装了自启的话，开机就会自己登录并保活，你不用管。
只想手动用、不要自启，安装时最后一步选 n 就行。


五、出问题了
--------------------------------------------------------------------
按这个顺序：

1. 先确认真的连在校园网里（UCLINK / UCSIG），不是热点。
2. 跑 campus-auth doctor，把输出原样发给维护者。
3. 说清楚卡在第几步、屏幕上的原话，别自己转述。

密码不会出现在 doctor 的输出里，可以放心发。


六、卸载
--------------------------------------------------------------------
  campus-auth uninstall          停掉并删掉自启
  campus-auth password --forget  删掉存着的密码

然后删掉这两个地方：
  %APPDATA%\campus-auth
  %LOCALAPPDATA%\campus-auth

只关了自启但没卸载干净的话，开机还会尝试登录。


七、校规与风险（摘要）
--------------------------------------------------------------------
- 非官方项目，和学校、Dr.COM 都没有关系。
- 只做登录/注销/保活，不改计费、不绕套餐。
- 门户改版或学校换策略就可能失效，失效期间可能影响你上网。
- 遇到账号被锁、流量异常，先找学校网络中心。

完整版见 免责.txt。
